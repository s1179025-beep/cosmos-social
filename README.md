# COSMOS · 星际漫游打卡

一个把「地球仪」当成入口的 3D 旅行社交平台：从星空中降落地球，点中国进入中国地表，再逐级下钻到省份、城市，在城市抽屉里看实景图集、实时天气和每个旅行者留下的朋友圈。

- 线上演示（完整功能，含云端账号与数据）：https://cosmos-social.app.workbuddy.host/?sharecode=WPUFSC7DGJ
- 纯静态预览（仅界面，登录与发帖不可用）：https://s1179025-beep.github.io/cosmos-social/

## 交互动线

```
星空 / 银河
  └ 地球（可拖拽旋转、缩放、聚焦）
      └ 中国（专题高亮，点击进入）
          └ 省份 / 板块（按真实边界高亮，自动放大）
              └ 城市（高德 POI 实景图集 + 实时天气 + 朋友圈）
                  ├ 评论舱（表情、回复、点赞）
                  ├ 发布舱（九宫格图片 / 60 秒视频 / 定位 / 表情）
                  └ 世界频道（最新 / 热门 / 附近，按时间流浏览全球分享）
```

每一级左上角都有返回小标，逐级退回上一层级。

## 技术要点

| 模块 | 实现 |
| --- | --- |
| 地球 | three.js 自定义 Shader（海 / 陆 / 中国三通道掩膜）、高程浮雕、波光效果、四元数 trackball、贝塞尔 FlyTo |
| 中国地表 | Leaflet + 省级 GeoJSON 挤出 3D，真实地表模式下逐级下钻（省 → 市 → 区县 → POI） |
| 地理数据 | DataV 行政区边界、高德 Web 服务（行政区检索 / POI 检索 / 天气） |
| 社交 | 云端数据库（profiles / posts / post_likes / comments / comment_likes / user_likes）+ 行级权限 |
| 身份 | 微信访客登录（免注册）、手机验证码登录（3 天内免登）、未登录也可浏览与互动 |
| 媒体 | 单次最多 9 张图（统一栅格布局）、最长 60 秒视频 |
| 部署形态 | 单文件 `index.html`，three.js / Leaflet / 云 SDK / 省界数据 / 贴图全部内嵌，零外部依赖 |

## 目录
